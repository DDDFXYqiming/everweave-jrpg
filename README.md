# Everweave · 未写之境

写下一段世界设定，走进由语言模型持续创作的像素 RPG。

你可以探索地图，与人物交谈，调查机关，收集物品。模型根据设定和已经发生的事情设计后续区域，也能为对象编写交互规则。走路、碰撞和已有规则在本地执行，冒险进度自动保存。

Everweave 使用 Godot 显示游戏，Python 管理世界状态。画面和声音优先从本地素材库选取，由模型组合并补充原创内容。目前仍是可玩的开发原型，生成速度、地图密度和谜题质量会随模型与题材变化。

## 开始一段旅程

需要 Python 3.11 或更高版本，以及 Godot 4 Standard。项目当前使用 Godot 4.7.2 测试。

Windows 用户可以把 Godot 可执行文件放在项目根目录或 `tools/`，然后双击 `Start.cmd`。也可以从命令行启动。

```powershell
python launch.py --godot ./tools/Godot.exe
```

如果 Godot 已加入 PATH，运行 `python launch.py` 即可。首次启动会下载清单中缺少的素材并核对文件哈希；需要重建拼接图时，相关工具安装在项目内的缓存目录。准备好资源以后，启动器会打开游戏并运行本机服务。

在游戏中填写世界设定，配置模型服务，然后开始新旅程。默认支持 DeepSeek，也可以填写兼容 Chat Completions 与 JSON 输出的服务。API Key 在设置中输入，或通过 `DEEPSEEK_API_KEY` 环境变量提供。

开始菜单上方可以切换简体中文和 English，游戏中也能从设置进入。界面立即更新，后续生成使用所选语言；已经保存的任务、剧情和对白保留原文。语言选择会保存，详细说明见 [语言设置](docs/LOCALIZATION.md)。

可以从这样一段设定开始。

> 我是来到潮雾港的测潮员。修船村的绞盘坏了，一艘小船被困在木码头。我想向船匠打听故障，找到灯塔值班室留下的维修记录。

在线生成会产生模型服务费用。界面可以设置调用上限、查看用量，也可以暂停后续生成。初次创建世界和准备新区域需要等待；已经生成的地图仍可继续探索。只想检查安装和操作时，可以选择不调用模型的离线自检。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 | WASD 或方向键 |
| 与相邻人物、物体或出口交互 | E 或空格 |
| 查看当前自定义操作 | F |
| 行囊与手记 | I、J |
| 展开旅途地图 | G，或点击小地图 |
| 等待 | `.` |
| 选择战斗操作 | 数字键，具体动作以界面为准 |
| 关闭面板 | Esc |
| 全屏 | F11 |
| 音乐开关 | M |

一个存档目录保存一个世界。想保留当前旅程并另开一局，可以指定独立目录。

```powershell
python launch.py --data-dir ./userdata/another-journey
```

安装、存档位置与模型设置的详细说明见 [使用指南](docs/LOCAL_SETUP.md)。

## 世界怎样生成

模型先获得世界设定、地区概要和一小组适用素材，再生成场景蓝图与玩法数据。引擎解析引用、展开可选模块并校验结果，Godot 把通过校验的内容呈现出来。后台会提前准备相邻区域，重要事件也可以引起新的世界变化。

地图尺寸、房间位置和对象行为由生成内容决定。草地、道路和墙面的细节由本地材质配方补充；装饰按固定种子布置，避免要求模型逐格画图。音乐可以随地区、战斗或剧情切换。

目前的素材库主要覆盖小镇与地下主题。其他题材会更多使用原创绘图，因此不同世界的美术完成度仍有差异。结构校验能发现越界、引用和执行问题，无法保证每个生成谜题都好玩、可解。
