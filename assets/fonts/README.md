# Bundled fonts

- `FusionPixel.ttf`: Fusion Pixel 12px Proportional Simplified Chinese, release 2026.09.01, from https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01 . Unmodified upstream font. SIL OFL 1.1, including component licenses in `fusion-licenses/`.
- `LXGWWenKaiScreen.ttf`: LXGW WenKai Screen v1.522, from https://github.com/lxgw/LxgwWenKai-Screen/releases/tag/v1.522 . Unmodified upstream font. License alongside this file.

The pixel face is used for compact HUD labels and controls. Longer narrative text uses WenKai. Full character coverage is retained for model-authored content; fonts are not reduced to the current UI's characters.
