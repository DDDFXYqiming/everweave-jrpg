# Bundled fonts

- `FusionPixel.ttf`: Fusion Pixel 12px Proportional Simplified Chinese, release 2026.09.01, from https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01 . Unmodified upstream font. SIL OFL 1.1, including component licenses in `fusion-licenses/`.

The pixel face is used for all interface and narrative text, rendered only at integer multiples of its 12px design size (12, 24, 36, 48) so glyphs stay pixel perfect. Full character coverage is retained for model-authored content; the font is not reduced to the current UI's characters.
