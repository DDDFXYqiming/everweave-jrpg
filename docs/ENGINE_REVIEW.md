# AI-JRPG Runtime 对齐与实测

2026-09-11。已逐页读完原对话全部 11 轮消息，从项目筛选到最终 Godot 方案；早期探索方向不覆盖最后确认的目标。

## 项目目标

开发可被 LLM 持续驱动的引擎和概念原型。玩家输入世界设定，模型创作具体场景、角色、物品、任务、地点和后续发展，运行时验证并落实为可操作对象。玩家行为再进入模型上下文，世界持续扩展。确定性代码负责通用执行原语、状态一致性和存档；样例剧情不代表引擎的创作能力。

## 本次完成

- 默认入口为 DeepSeek 在线生成，另有兼容服务。离线样例明确标成引擎自检，三种模式互斥；切换后只显示相关配置。
- 服务配置可保存、恢复，不保存明文 key、不在启动时自行调用模型。DeepSeek 环境密钥只供官方 DeepSeek 接口使用。
- 在线区域生成必须声明 1～2 个目的地概要，后续请求收到对应概要。运行时负责稳定连接 ID、位置与回访；不再强制每张在线地图产生两个无名出口。
- 世界反应支持新物品、实体、任务和地点入口的共同注册与引用解析；每份补丁最多 2 项各类新增内容，每区最多 4 条前向道路。
- 失败补丁整份回滚；悬空物品/任务引用进入最多一次的修复流程。修复也计入预算。
- 保留失败反应的待办状态，手动重试能继续原任务。在线请求失败不会调用离线样例生成器。
- 客户端拒绝过期快照，避免回到未开局状态；提交期间防止重入；覆盖确认在创建后清除。
- 修复超大请求在 Windows 上偶发无法收到 413 的问题，以及原生测试退出时的音频资源残留。

固定样例的剧情、地图和敌人定义保留。

## 验证证据

- `python -m unittest discover -s tests -q`：80 项通过，包含新增内容可交互、任务引用、原子回滚、概要传递、命名空间、重试、配置恢复与密钥边界。
- 原生场景检查：`GODOT_CLIENT_SMOKE_OK`，无脚本错误或退出资源错误。
- `python tools/test_native.py`：实际 Godot + 本地 HTTP 后端，119 次动作、两张地图往返。使用隔离存档，0 次云请求。截图在 `userdata/e2e/`。
- 真实 DeepSeek 新世界：原始设定为星空漂流群岛和调查陌生信号的邮差。模型创建「星屿邮站·初坠环礁」，声明「回声浅滩」「螺旋港」；玩家选择「那道信号是什么？」后生成新邮筒、NPC 与后续线索，再生成「回声浅滩」。通过真实移动/交互进入新图并返回原图，原图 tiles 一致。
- 最后一次完整联调 3 次请求全部接受，无修复；usage 输入 7,809、输出 2,984 tokens。原始响应、上下文、阶段结果与隔离存档在 `userdata/runtime-validation-v3/`。此前两次探索运行另有 4 次请求失败或部分成功，已用于修复协议问题，不能计入成功率。
- 付费重测入口 `tools/test_live_runtime.py --live --output <新的隔离目录>`，要求通过环境变量显式提供 key，每次最多 6 个请求；普通测试不会启动该脚本。

## 后续修复：思考配置与重建世界

- 默认 `thinking=enabled`、`reasoning_effort=low`。DeepSeek 提供 low/high/max/none；其他兼容接口提供等级选择及不发送参数的服务默认选项。旧设置缺少此字段时采用 low，已保存的显式选择会恢复。
- 思考模式为推理和最终 JSON 合计保留输出预算：low 8192，high 16384，max 32768 tokens；非思考仍采用原来的 3600/1500。只解析最终 content，思考文本不保存到世界。
- 重建入口替换容易漏看的覆盖复选框。按钮显示“重新生成世界”，弹窗预览新设定；取消保留当前世界，确认后提交 replace_save，建立新 epoch、清空旧世界进度。过期响应不会写回，也不会继续为已替换世界追加修复请求。
- 增补后 85 项 Python 测试通过；原生检查通过，原生 HTTP 端到端测试验证了取消/确认重建、背包重置、全新地图及旧快照隔离（`NATIVE_REBUILD_OK`）。
- 真实 low 联调 3 次全部接受：开场 13.59 秒、反应 6.66 秒、下一区域 18.08 秒；接口返回累计思考 3631 tokens。输入 9197、输出 7335 tokens，思考计入输出。已完成两区域往返。证据在 `userdata/runtime-validation-low/trace.json`；这是单次样本，不构成各等级速度对比。
- 官方参数依据：[DeepSeek 思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。

## 当前表达边界

该阶段改善了创作协议与可靠性，以下限制对应当时版本。运行时仍是有限的二维地图/实体/物品/任务/战斗原语；地图固定尺寸、连接仍为树结构，未提供任意世界图、室内系统、组合技能语言、完整章节导演、动态角色部件合成或自然语言自由行动。模型只能创作这些原语能表达的内容。

继续开发应优先提升模型可调用的通用原语、持续世界记忆、生成一致性与不同设定的真实评测，避免把固定样例内容的丰富程度当作引擎完成度。
