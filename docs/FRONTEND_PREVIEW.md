# 前端第一版（2026-09-12）

该阶段更新了 Godot 前端、只读显示适配、窗口配置与前端测试。

## 界面

- 使用墨绿、暖灰、米色的界面与原创线条图标；开局背景为程序绘制的等高线。游戏场景与物品的模型绘图继续沿用原数据。
- 行囊分为物品格与详情，按补给、武器、饰物、要物和工具筛选。已有 `icon_visual` 显示原图，无专属图像的物品使用界面类型标记。点击物品只查看，使用或装备需另点明确按钮。
- 使用动作优先显示现有 `use.label`。任务物品、已装备状态、数量按快照呈现；前端不重新计算规则或杜撰功能。
- 手记展示待办、线索、最新经历及已结束任务，包括模型目标说明。仅展示后端快照提供的记录，不宣称已加载全部历史。
- 开局/设置分为旅程、显示与声音、连接三页。API 参数保留在连接页；状态诊断默认折叠，具体错误仍可查看并定向重试。
- 暂停和重试保持在右栏顶部。短交互弹窗随内容收缩，长内容限高滚动；阅读行囊/手记时屏蔽移动、等待等游戏按键。
- `canvas_items + expand` 保持图像比例并扩展可见区域；支持 F11 / Alt+Enter 全屏切换。小地图在可用视野中居中。

## 数据边界

`client/presentation.gd` 仅投影已有快照。保留物品和任务 ID；兼容缺失的可选展示字段、文字及结构化经历；不修改原快照，不在前端修复模型契约或运行条件表达式。原来的 epoch、版本、请求序号与动作 HTTP 链路继续保留。

## 自测

- Godot 客户端、可执行内容、只读展示适配测试通过。
- 原生 HTTP 回归通过，包含实际输入、生成动作、战斗、重试、出口等待窗口；基础原生旅程记录中执行 131 次操作，世界重建检查通过。

- 新世界存档 `userdata/ui-preview-20260912`，不覆盖旧的 `play-session-20260911`。开场与下一区域沿用原后端，各经过生成和原有修复流程，总计 4 次真实请求，两个地区准备成功。
