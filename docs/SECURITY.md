# 安全边界

## 本机服务与凭据

Python 服务只监听回环地址，使用每次启动生成的随机令牌验证客户端请求，并拒绝浏览器跨源访问。令牌保存在当前存档目录的 `runtime.json`，用于本机进程通信。

默认的 ChatGPT 订阅模式由 `subscription_auth.py` 执行设备 OAuth。Windows 上访问令牌和刷新令牌通过当前用户 DPAPI 加密，保存到用户数据目录的 `EverweaveJRPG/chatgpt-subscription.bin`，不进入世界存档、仓库、快照或日志。API Key 只在用户明确选择兼容 API 服务时使用，来自设置、环境变量或本地加密凭据。

Everweave 不读取 Codex CLI 或其他项目的认证数据库，也不复制其他应用的令牌。登录状态接口只返回 `ready/pending/failed` 和设备码，不返回 access token、refresh token 或账户标识。日志对已知凭据及常见敏感字段脱敏；主动写进世界设定或角色对白的私人信息仍可能被保存并发送给模型服务。

订阅直连只访问固定的 ChatGPT Codex Responses 地址，使用 SSE 和 `store=false`；请求不启用工具。兼容 API 模式要求 HTTPS，HTTP 仅允许本机地址，模型请求重定向被拒绝。填写的服务地址会接收生成所需的世界设定和游戏上下文，使用前应确认服务提供方。

## 生成内容

模型返回受校验的 JSON 数据，不能提交 Python、GDScript 或任意文件路径。素材引用必须在本地索引中，下载和缓存核对版本固定的哈希。

模型可以定义改变数值、对象和地形的规则。这些规则通过有预算限制的解释器执行，动作和存档更新在事务中完成；失败时回滚。结构、引用与空间检查无法证明任意谜题一定可解，也不保证生成文本没有矛盾。

## 提交与问题反馈

不要提交密钥、私人存档或原始生成日志。项目的 Git 忽略规则覆盖常见运行时数据，但忽略规则不会删除已经存在于 Git 历史中的内容。

发布前应同时检查当前文件和可达提交历史。日志及截图仍需要人工查看，模式扫描无法识别所有私人信息。发现真实凭据曾进入历史时，应撤销或轮换凭据，再单独处理相关历史。Git 服务何时回收强制更新前的不可达对象不由项目控制。

仓库中的 `Publish-Private.ps1` 是早期私密建库工具，不参与运行时，也不负责公开发布或清理已有 Git 历史。公开仓库前应扫描当前文件和全部可达提交历史；`.gitignore` 只阻止新文件进入索引，不会清除历史内容。
