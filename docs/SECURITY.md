# 本机与模型边界

## 凭据

API Key 只放在 Godot 输入框及本机 Python 进程内存；完成交接后输入框清空。Key 不加入 world context、SQLite、项目配置、常规日志或上传内容。可从本机 `DEEPSEEK_API_KEY` 环境变量读取，但不自动读取仓库 `.env` 文件。

本机桥接令牌每次启动重新生成，写到用户数据目录的 `runtime.json`，不在项目内。POSIX 上设置文件模式 0600；Windows 使用当前用户的数据目录权限。该令牌只是本机进程间令牌，不是模型 API Key。客户端和本机管理员仍能接触进程内存；不声称能防御已控制操作系统的攻击者。

## 请求

服务只绑定 `127.0.0.1`，拒绝非回环绑定。请求需 Bearer 令牌、正确本机 Host；带 Origin 的浏览器请求会被拒绝，不开放 CORS。限制 JSON 请求体大小，显示/日志不包含认证头或原始请求体。

向远程模型发送请求要求 HTTPS；HTTP 仅允许 localhost。模型服务的 HTTP 重定向会被拒绝，避免认证头跟随未知目标。玩家明确填写的服务地址会接收世界设定与相关游戏事实，不会读取其他本机文件。模型请求只支持 Chat Completions JSON 输出，不调用任意模型工具。

## 模型输出

固定字段、固定枚举、长度/数量限制、效果兼容检查、物品预算限制、任务引用检查、受控实体放置、连通性检查。未知字段拒绝，生成脚本无执行入口，外部资源路径无加载入口。已经访问的地形无法被 reaction 替换；玩家 HP、金钱和库存没有对应模型补丁字段。

严格结构校验不能证明所有故事文本都合理或毫无矛盾。它保证的是模型无法靠叙述直接修改权威数值和已访问地图，而不是宣称解决所有长篇叙事一致性问题。

## GitHub

没有自动公共仓库回退。发布脚本默认创建私密仓库，检查登录账号、推送前后读取 privacy，拒绝同名公共库或非空库，拒绝不匹配的 origin，无 force push。上传文件使用明确允许清单，过滤存档、常见密钥文件、引擎二进制和缓存，并检查明显的嵌入式凭据。扫描不是通用 DLP，手动添加私密内容后仍应审查 `-DryRun` 输出。
