# 混合内容重构方案

分支：`codex/hybrid-content-library`。从 `2d071cc` 开始，保留已有世界状态机、空间蓝图和有界规则解释器。

## 先建立可引用的材料

第一批采用适合俯视像素游戏的 CC0 素材，统一记录来源页、作者、许可、包版本、下载地址与 SHA-256。图像索引记录视角、尺寸、锚点、用途、风格；音频记录类型、循环与音量信息。原包与运行时资源留在本地缓存，仓库保存来源、许可和重建清单。

素材以稳定 ID 引用，运行时只接受索引中的 ID；不接受模型提供的文件路径、URL 或脚本。已引用的版本不可被同名新文件悄悄替换。

## 同一地区可以混用三种来源

1. 库内图像/音频直接引用。
2. 库内图像部件叠加、变体，或多个音效组合。
3. 沿用像素绘图与可执行规则补缺口，并提供短乐句/合成音效的数据表达。

复用比例随场景需要调整，不设固定配额。主角身份和已访问世界保持连续。

## 不把全库传给模型

先按设定、地区概要、风格兼容性和近期使用记录进行本地检索，只提供一组候选及简短用法。已有目标描述足够时，一次模型请求直接编排；不为每个地区强制增加一次规划请求。缺少匹配材料时允许原创，不悄悄替换为不合题材的素材。

能力库提供经过测试的可选规则模块，展开成现有 DSL 后完整校验。模块不强制安装；模型可以连接模块与原创规则。新增音频同样随地区保存：探索/战斗主题切换、事件音效、对象音效和自定义音乐事件由数据控制。

## 验收

验证未知 ID/错误版本/越界组合拒绝、模块展开与事务回滚、旧存档兼容、音频切换/去重/静音，以及实际客户端渲染。用村落与地下遗迹两个场景检查同图混用、画面和玩法；记录真实请求耗时、输入/输出 tokens 和修复次数。候选包字节减少不能直接当成实际延迟降低。
