# 生成节奏、任务披露与敌人行为

本轮从 `main / 14839df` 继续，处理生成作废、任务剧透、固定中段规划与静止敌人。原混合资产索引和本机缓存保留，存档与玩家动作仍由同一后端维护。

## 生成如何避免无效工作

- 没有实质新增的复盘只确认已处理事件，不增加设计版本。地区请求检查目标草案、相关人物、技能和委托的依赖摘要，其他地方新加一条支线不会使其整体报废。相关人物死亡或技能定义冲突仍不能忽略。
- 复盘接受请求开始时的一批事件，期间产生的新事件保留到下一批；提案在当前权威状态上重新校验。它不能改写已经完成的事实，也不能自动恢复死者。
- 选择、胜利、任务变化和已有人物状态变化进入重要复盘候选。普通查看/使用按最近 64 条语义记录去重，累计 8 条且距上次复盘 90 秒后再处理。普通走路不发模型请求。
- 两路并发保持不变。玩家等待的出口、开局地图优先，附近地区至少先取得一路生成机会，然后安排当前委托、重要复盘和其他预取。
- 地区上下文保留相关路线条件，减少远处的制作说明；要求先交付一组重点对象和动作，使用本地材质与点缀，避免手写逐格装饰。这是生成提示，不是以丢弃内容换取通过率。

回归通过真实 `Director.step()` 验证了请求期间发生空复盘后，结果仍能保存：一次请求、一次应用、零过期。并发、过期与玩法测试不消耗模型额度。这证明该浪费路径被修复，不能据此换算线上整体提速倍数。

## 任务与滚动中段

任务卡位于地图左上角，点击或按 **Q** 打开行动记录，可查看进行中、已完成及已经知道的前置关系；更早记录继续通过分页手记查看。右侧不再堆叠章节目标和全部里程碑。

`player_quests()` 为快照、手记和旅图提供同一份可见任务。主线也需要发现或前置任务完成，可用 `reveal_when` 控制披露；已发现记录持续保留。全局任务与同名局部目标避免重复显示，未知任务不会靠打开另一页面泄露。章节内部用途、解决条件与结局方向不作为任务清单直接返回。模型自己写进公开对白的剧透仍需内容审查，接口隔离不等于文本一定无剧透。

新在线提示要求 `planning:rolling`：先规划眼前 **2～4 个地区**，把远期方向留在私有 `ending_brief`，保留章节局部收束与接续。`planning:chapter` 仍支持旧的 4～8 地区完整计划。

全局导演可通过 `new_regions` 一次追加至多 2 个实际地点，并通过真实 `links` 接入；添加地点时最多 4 条连接，否则 2 条。新增旗标和制作委托一起声明。每章最多 16 个地点；既有地点继续受两个预留门口限制。校验拒绝孤立的新地点、重复路由 ID、被占用的门口和无效提案，并原子回滚。

这是允许逐步扩展中段的实现，不是任意改写历史地图。滚动开局也不强迫两三个地点立刻构成大型网络；是否主动追加合理分支与回环仍取决于导演的创作，需要多轮游玩验证。

## 大地图上的敌人

模型可以定义：

```json
{"behavior":{"mode":"patrol","radius":5,"leash":10,"pace":2,"engage_range":1,"patrol":[[8,6],[14,6]],"when":true},"footprint":[2,2]}
```

`mode` 为驻守 `guard`、巡逻 `patrol` 或追击 `hunt`。行为随普通移动/等待回合推进，读取同一套受限条件表达式，不额外调用模型。墙和实心门遮挡发现视线；移动尊重地图碰撞、其他对象、出口及自身占地。接近到交战距离会发起真实遭遇；守卫若有交涉动作，也可以先呈现相应交互。警戒时显示标记，多格敌人显示占地区域。

有界寻路每次最多检查 384 个候选位置，复杂地形可能停下。它不是连续实时 AI 或无限寻路。撤离后有 3 个行动回合的脱离窗口，防止原地立即再战。

新冒险的在线敌人必须给出 `behavior` 或相应的大地图行动钩子，仅提供 `enemy_turn` 不够。驻守是合法设计，并非所有敌人都强制追击。区域作者仍须设计资源代价、奖励、通路或故事后果；引擎不自动把所有敌人塞到主路上，也不强迫和平世界出现战斗。

## 本轮验证

**286 项 Python 测试通过**。Godot 原生检查覆盖了任务卡真实点击、Q 关闭、未知任务不显示、原有剧情与跨区能力，以及守卫移动、多格占地、自动开战、反击与撤退。原内容、混合素材、旅图方向与音频回归通过。

独立在线世界使用夜之城佣兵护送医护人员的设定，生成了 3 个计划地点，完成开局“千叶町雨巷”。测试过程保留失败：

| 请求 | 用途与结果 |
|---|---|
| 1～2 | 开局计划；首次 `failure_mode` 放错层，修复后接受 |
| 3～4 | 开局地区；音效绑定内嵌配方未通过旧格式处理，地区未保存 |
| 5～6 | 保留原输出的定向修复，补足敌人大地图行为；中间一次返回不合法 JSON，最终通过 |

6 次请求累计输入 **70729**、输出 **80598 tokens**，服务请求时间约 **316.6 秒**，未计算调试和操作时间。这仍然偏慢，且不是与同条件旧版作对照的基准。不能宣称完整地区已能秒出，也不能把失效减少当成模型本身变快。

失败推动了两项本地修正：无歧义的 `campaign.failure_mode` 移到 `game_spec`，冲突仍拒绝；内嵌音效配方归一化为稳定 cue，保留音量/音调并区分同素材的不同配置，继续正常校验而不丢字段。音频错误也会和其他独立字段问题一起报告。不会替模型编一个固定敌人行为来绕过失败。

快速自主试玩依据玩家可见数据选择操作，完成接头谈判、追问芯片信息、接近守卫进入警戒、无需点击触发战斗、消耗弹药攻击并获得结算。12 次观察/意图命令包含 21 次正常移动，移动批次执行合计约 **1 秒**，不含判断和工具往返。精确射击消耗 3 发弹药，敌人反击造成 8 点伤害；最终完成西院支线。实际模型选择了驻守行为，移动追击由原生固定回归另行验证。

本地证据位于 `userdata/pacing-validation/`：原始生成 trace、失败和修复结果、独立数据库、`play.jsonl` 与 `gallery/`。这些私人运行内容不提交到 Git。当前只游玩了首个地区，未完成整章、持续扩图、多题材成功率和长期平衡验收。完整生成的输出量、原创美术质量和重试次数仍是后续性能重点。
