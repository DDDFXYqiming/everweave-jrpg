# 六项审查问题的修复与自测

这次修改落实了审查表中的六项修复。原工作区中已经存在的 SSE 补试、连接恢复和文档修改继续保留。

| 问题 | 修复 | 自测证据 |
|---|---|---|
| ready 地区进入失败后无法重试 | 发布前隔离执行各入口；实际进入失败时回滚、保存内容失败并接入地区重试 | 动态除零、入口坐标相关错误被拒绝；旧 ready 数据故障后重新加载、重试、正常进入成功 |
| 自锁目标通过校验 | 旗标、钥匙、资源上界与有向路线的保守固定点检查；独立正常动作回放 | 自依赖旗标、钥匙无生产者、资源自举和门后生产自身通行旗标均被拦截；四地区测试章节存在正常动作完成轨迹 |
| 成功组件丢失和用量漏记 | SQLite 组件续作和逐请求账本；依赖/提示变化使缓存失效 | 一路失败再重启，只有失败分支请求一次；账本保存双方用量；全组件完成后可以零请求发布 |
| 非法 JSON 无法修复 | 保留有界原始文本和解析诊断；每个分支独立修复预算 | `{` 响应进入修复并成功；两路分别错误时各修一次 |
| 跨分支音频引用缺失 | 共享 cue 约定，组装时交叉校验并定位责任分支 | 补齐 `gate_open` 只重试视听，玩法请求保持一次 |
| 扣费不足仍能执行 | `costs` 统一预检、扣除、可用状态及说明；旧主动效果非生命扣费禁止透支 | 不足余额禁用；多资源支付与后续错误原子回滚；剧情选项、物品与环境损耗分别验证 |
